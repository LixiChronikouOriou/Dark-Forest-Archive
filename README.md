# Dark Forest Archive

Collection of inactive (not touched for years) or abandoned (declared as such or deleted repository) projects which introduce material for new species. Archived for inspiration and hopefully some kind of revival.

The difference to the races section of the [Plugin Archive](https://github.com/Hecter94/EndlessSky-PluginArchive) is that it also includes archaeological material which was never published.

There might be interesting species out there in the wild. Feel free to contact me via issue or PR here on Github, or in the corresponding [Discord channel](https://discord.com/channels/251118043411775489/1432671335623954472) if you see something interesting to preserve.

**Thanks**: 1010todd and The_Legendary_M for research help, and of course all authors.
